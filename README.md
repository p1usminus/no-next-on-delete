# No Next Message on Delete - fork #

This is a fork of the Thunderbird extension *No Next Message on Delete* created by [shumashgeely](https://connect.mozilla.org/t5/ideas/don-t-select-next-email-after-delete/idc-p/135670/highlight/true#M68787) available on the Thunderbird Add-ons site [here](https://addons.thunderbird.net/en-us/thunderbird/addon/no-next-message-on-delete/). Please check there for a full description.

It replicates the function of an older, now defunct, extension, [Deselect on Delete](https://addons.thunderbird.net/en-us/thunderbird/addon/deselect-on-delete-tb78/).

This fork makes some small changes:
* Keyboard shortcut is added: default is Ctrl+Enter but this can be changed
* Fixed function when using table view
* Updates installed from this repo
